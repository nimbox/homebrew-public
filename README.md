# nimbox/public

The nimbox Homebrew tap:

```sh
brew tap nimbox/public
brew install --cask nimbox/public/tower
```

Casks live in `Casks/` and are **generated by GoReleaser** on each tool's
release — do not edit them by hand; the next release overwrites them.
(Formulas at the repository root are the older generation: GoReleaser
removed its `brews` support, so new tools ship as casks.)

## Tools in private repositories

Homebrew downloads release assets anonymously, so a cask pointing at a
private repository's release fails with 404. Those casks download through
the GitHub API instead, using `lib/private_strategy.rb` (shared by all of
them), and require a token on the installing machine:

```sh
export HOMEBREW_GITHUB_API_TOKEN=<a PAT that can read the tool's repository>
```

One export, once, covers every private tool in the tap. The tool's binary
still authenticates its own way (crew credentials, etc.) — the token is only
for fetching the download.

To add a new private tool, its `.goreleaser.yaml` `homebrew_casks` entry
needs these pieces; everything else is the normal GoReleaser setup:

```yaml
homebrew_casks:
  - name: <tool>
    repository:
      owner: nimbox
      name: homebrew-public
      token: "{{ .Env.TAP_GITHUB_TOKEN }}"
    custom_block: |
      require_relative "../lib/private_strategy"
    url:
      using: GitHubPrivateRepositoryReleaseDownloadStrategy
      verified: github.com/nimbox/<repository>/
```

Two facts every unsigned CLI cask must respect: casks quarantine their
downloads, so a `postflight` strips the attribute from the binary
(`xattr -dr com.apple.quarantine`); and the install sandbox kills the
binary if executed, so shell completions must ship as files inside the
release archives (`before` hooks + `archives.files` + the `completions`
mapping), never via `generate_completions_from_executable`. See
`nimbox/tower`'s `client/.goreleaser.yaml` for the reference setup.

## Migrating from a formula

A tool that moved from a root formula to a cask installs fresh once:

```sh
brew uninstall <tool> && brew install --cask nimbox/public/<tool>
```
